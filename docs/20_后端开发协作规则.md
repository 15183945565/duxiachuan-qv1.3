# 后端开发协作规则

本文档是后端侧专用规则，主要说明后端同学如何使用前端仓库、哪些前端内容可以改、哪些不要改，以及如何把服务器部署和前端联调分清楚。

更新时间：2026-08-01

## 后端仓库

后端仓库：

```text
https://github.com/15183945565/duxiachuan-server.git
```

后端技术方向：

```text
Java
Spring Boot
Maven
JDBC
WebSocket
```

## 后端负责范围

后端主要负责：

```text
玩家账号
登录鉴权
玩家存档
背包物品
战斗结算
排行榜
分享任务
道友数据
充值提现
数据库
WebSocket
服务器部署
```

## 后端如何使用前端仓库

后端同学需要从前端仓库拉取 Cocos 工程：

```bash
git clone https://github.com/15183945565/duxiachuan-qv1.3.git
```

每次联调前：

```bash
git pull --ff-only origin main
```

后端如果修改了前端，也必须提交回前端仓库：

```bash
git status -sb
git add .
git commit -m "net: 接入xxx接口"
git push origin main
```

## 后端可以改的前端内容

后端同学优先只改这些：

```text
接口地址配置
ApiClient
ApiRoutes
ApiTypes
WsClient
Mock 切真实接口
页面脚本里的数据绑定部分
少量和联调直接相关的逻辑
```

推荐前端接口相关目录：

```text
assets/Script/Net/
assets/Script/Data/
assets/Script/Mock/
assets/Script/Config/
```

## 后端尽量不要改的前端内容

除非提前沟通，否则不要改：

```text
MainScene.scene
LoadingScene.scene
大型 .prefab
资源 .meta
UI 节点层级
图片资源 uuid
Spine 资源
图集资源
```

如果必须改 UI 或 Prefab，先告诉前端：

```text
要改哪个页面
要改哪个 prefab
会不会保存 scene
改完需要前端检查什么
```

## 接口变更规则

后端接口变化必须同步说明：

```text
接口路径是否变化
请求参数是否变化
返回字段是否变化
字段类型是否变化
错误码是否变化
是否影响已有页面
```

优先更新：

```text
docs/15_现有接口文档草案.md
```

或者新增接口变更记录。

## 接口路径规则

前端希望使用相对路径：

```text
/api/player/profile
/api/bag/items
/api/share/tasks
/api/daoyou/list
/ws
```

后端部署时通过服务器或 Nginx 做转发，不要要求前端在代码里写死服务器 IP。

## 后端推回前端时要说明

后端同学如果改了前端并 push，需要告诉前端：

```text
改了哪些前端文件
接了哪些接口
哪些地方还在 Mock
是否改了 UI / Prefab / Scene
是否新增或修改了接口字段
是否需要前端打开 Cocos 检查
```

如果改了 `.scene`、`.prefab`、`.meta`，必须特别说明。

## 服务器部署规则

当前模式下，服务器主要由后端同学负责。

推荐服务器部署来源：

```text
GitHub 最新代码
明确的 commit
明确的构建产物
明确的后端 jar
```

不要在服务器上直接手改代码后不提交 GitHub。

标准流程：

```text
本地改后端
本地测试
push GitHub
服务器拉取
Maven 打包
部署 jar
部署前端 build
手机测试
```

## 生产敏感信息规则

这些东西只能在后端本地或服务器安全位置保存，不能提交 GitHub：

```text
数据库密码
JWT 密钥
支付密钥
短信密钥
后台管理员密码
服务器私钥
生产环境 .env
真实玩家隐私数据
```

GitHub 仓库里只能放：

```text
.env.example
application-example.yml
README 配置说明
```

## 后端当前重点

当前前端仍在快速完善 UI，后端联调时建议优先接稳定模块：

```text
玩家基础信息
背包物品
分享任务
道友列表
战斗结算
排行榜
```

暂时不要深度绑定还没定稿的 UI 页面。等前端页面稳定后，再接真实数据。
