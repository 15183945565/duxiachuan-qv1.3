# 后端联调交付清单

## 结论

Qv1.3 已达到“可交给后端评审接口并并行开发”的前端工程标准，但还没有达到“连接服务器即可完整联调”的状态。

已完成的是场景、节点、代码模块、资源生命周期、功能 Bundle、Release 构建和自动门禁。仍阻塞端到端联调的是账号协议、Bootstrap 回填、页面事务接线、错误状态和环境配置。宗门、礼包按产品决定冻结；分享任务与道友页面已解冻，接口契约见 `13_分享与道友开发说明.md`。

## P0：开始真实联调前必须完成

| 项目 | 当前状态 | 前端动作 | 后端输入/责任 | 验收标准 |
|---|---|---|---|---|
| OpenAPI 契约 | 未锁定 | 按最终契约修改 DTO 和 Remote 方法 | 提供接口、字段、错误码、示例 | 前后端使用同一份版本化契约 |
| 手机登录 | 本地模拟 | 接验证码、登录、刷新、退出 | token、过期、风控、重试规则 | 刷新页面仍可恢复会话，失效后回登录 |
| 环境注入 | 前端入口已落地 | 部署时替换非哈希 `runtime-config.js` | 提供四套环境地址、CORS 与缓存规则 | 源码不含生产密钥和硬编码生产地址 |
| Bootstrap | 只调用不回填 | 建立 Session/Store 并原子回填 UI | 返回完整角色和资产快照 | 角色、货币、背包、开关均以服务端为准 |
| 真值迁移 | 多处 localStorage | 按功能移除服务端字段的本地读写 | 保证查询/事务接口完整 | 同一字段不存在双真值 |
| 事务幂等 | 未定义 | 发送 requestId/idempotencyKey，处理重复响应 | 邮件/购买/交易/结算幂等 | 重试不会重复扣款或发奖 |
| 错误状态 | 演示级 | 补 Loading/Empty/Error/Retry/超时/取消 | 稳定 errorCode 与 HTTP 语义 | 断网、超时、401、409、5xx 可恢复 |
| 版本协商 | 未定义 | 上报客户端/资源/渠道版本 | 维护、灰度、强更策略 | 旧版本得到明确维护或升级页面 |

## P1：首轮联调功能顺序

建议按依赖从小到大接入：

1. 登录、会话恢复、Bootstrap。
2. 角色资料、货币、背包只读展示。
3. 邮件列表、阅读、单领、全领和删除。
4. 商城商品、购买、限购和余额刷新。
5. 集市列表、上架、购买、并发冲突和交易记录。
6. 角色升级、突破、装备替换、强化、分解和合成事务。
7. 排行榜。
8. 征战/魔界开战、服务端种子、超时和结算。
9. 对决状态与战绩。

每接入一项，都要删除该项线上字段的本地真值，并保留 `LocalPreviewBackend` 作为明确的离线演示模式，不能静默混用。

当前 Release 基线：

- Cocos Creator 3.8.8。

- 设计分辨率 `750×1624`，`FIXED_WIDTH`，竖屏。

- `RemoteGameBackend` 统一校验绝对 HTTP(S) 地址并编码路径参数。

这表示传输底座可以进入接口评审和 Mock Server 对接，不表示页面已经完成 Remote 数据接线。

## 资源发布决策

当前功能 Bundle 保持本地，是因为 CDN 地址、跨域、缓存和回滚方案尚未确定。Cocos 要求远程 Bundle 与资源服务器地址配套；不能先勾远程包再等待后端补 URL。

上线前需共同确认：

1. CDN 根地址、HTTPS、CORS、回源和目录结构。
2. MD5 资源的长期缓存与 HTML/settings 的短缓存策略。
3. JS/JSON/TTF 的 Brotli/gzip。
4. `feature-magic` 等大功能包是否远程化及失败重试页面。
5. Web、Android、iOS 分别使用的纹理压缩配置。
6. 资源版本回滚和灰度规则。

当前 1603 张图片尚未配置平台纹理压缩。不能在未做画质分级和真机兼容矩阵前全量套 WebP/ASTC；应先从大背景、Spine 页和不透明 UI 建立小批量预设，完成视觉对比和内存测试后逐批启用。

## 当前首包大头

启动原始响应 43.58 MiB，主要来自：

- `SIMKAI.ttf`：11.23 MiB。
- 登录与主城音乐：约 7.49 MiB。
- Cocos 引擎脚本：约 2.99 MiB。
- 男女主城角色、Loading Spine、登录背景/Logo和主城背景。

字体不能直接按现有静态文案裁剪，因为昵称、公告和后端下发文本可能包含未收录汉字。若要子集化，后端必须先提供完整运营字库范围，并为用户输入和未知字符设计回退字体。

## 联调完成定义

只有同时满足以下条件，才可把前端标记为“首版后端联调完成”：

- P0 全部完成。
- P1 已约定范围全部使用 Remote 后端并通过弱网/重试测试。
- 服务端字段不再由 localStorage 同时维护。
- 登录到主城以及邮件、商城、集市、养成、战斗主链路通过。
- `npm run check:all` 与 `npm run check:delivery:release` 通过。
- Release 构建在目标手机尺寸运行，无错误、缺资源、超预算和功能包启动泄漏。
- 前后端共同签字确认 API、资源版本和回滚版本。
