# 角色选择页编辑说明

本页对应 Cocos 编辑器节点：

```text
Canvas
  MainRoot
    PageLayer
      CharacterCreatePanel
```

如果编辑器标题里的 `MainScene.scene` 后面有 `*`，说明当前编辑器里有未保存改动。若画面已经乱了，先不要保存，重新载入 `assets/Scene/MainScene.scene`，再继续调。

## 最常改的内容

### 1. 整个角色选择页

节点：

```text
CharacterCreatePanel
```

用途：整个创建角色页面的大根节点。

注意：这个节点默认是隐藏的，因为主界面不应该一直显示角色选择页。需要在编辑器里调整时，可以临时勾选 active；调完后建议关掉，避免主界面被盖住。

### 2. 背景图

节点：

```text
CharacterCreatePanel > CharacterSelectBg
```

可改：位置、尺寸、SpriteFrame。

正常尺寸：

```text
Position: 0, 0
Content Size: 750 x 1624
```

### 3. 女角色大立绘

节点：

```text
CharacterCreatePanel > CharacterPreviewRoot > CharacterSelectRole_female
```

可改：Position、Scale、Spine 组件。

当前默认值：

```text
Position: 0, -54.099
Scale: 3, 3
Content Size: 760 x 1280
```

### 4. 男角色大立绘

节点：

```text
CharacterCreatePanel > CharacterPreviewRoot > CharacterSelectRole_male
```

可改：Position、Scale、Spine 组件。

当前默认值：

```text
Position: 76, -54.099
Scale: 3.2, 3.2
Content Size: 760 x 1280
```

注意：男角色默认隐藏，避免在编辑器里和女角色叠在一起。要调男角色时，临时勾选这个节点 active；调完可以关掉。运行时点击男角色卡会自动显示男角色。

### 5. 说话气泡

节点：

```text
CharacterCreatePanel > CharacterSelectSpeechBubble
CharacterCreatePanel > CharacterSelectSpeechBubble > CharacterSelectSpeechText
```

可改：气泡位置、大小、气泡文字位置。

默认值：

```text
CharacterSelectSpeechBubble Position: -206, -90
CharacterSelectSpeechBubble Content Size: 424 x 214
CharacterSelectSpeechText Position: -18, -8
CharacterSelectSpeechText Content Size: 260 x 56
```

### 6. 女/男角色选择框

可见卡片节点：

```text
CharacterCreatePanel > CharacterSelectCardRoot > CharacterSelectCard_female
CharacterCreatePanel > CharacterSelectCardRoot > CharacterSelectCard_male
```

它们用于编辑器里看当前预览效果。

但是运行时“选中变大、未选中变小、前后交错”的位置，主要看下面四个布局节点。

### 7. 选择框交错布局

布局节点：

```text
CharacterCreatePanel
  CharacterSelectCardRoot
    CharacterSelectCardLayouts
      CharacterSelectCard_female_SelectedLayout
      CharacterSelectCard_female_NormalLayout
      CharacterSelectCard_male_SelectedLayout
      CharacterSelectCard_male_NormalLayout
```

这四个节点是最关键的。

含义：

```text
CharacterSelectCard_female_SelectedLayout = 女角色被选中时，女框的位置和大小
CharacterSelectCard_female_NormalLayout   = 女角色未选中时，女框的位置和大小
CharacterSelectCard_male_SelectedLayout   = 男角色被选中时，男框的位置和大小
CharacterSelectCard_male_NormalLayout     = 男角色未选中时，男框的位置和大小
```

默认值：

```text
女选中: Position -162, -315.127 / Content Size 426 x 214
女未选: Position -162, -399.127 / Content Size 322 x 152
男选中: Position  162, -315.127 / Content Size 416 x 214
男未选: Position  162, -399.127 / Content Size 324 x 168
```

调法：

```text
想让选中框更大：改对应 SelectedLayout 的 Content Size。
想让选中框更靠上：改对应 SelectedLayout 的 Y。
想让未选框更靠后/靠下：改对应 NormalLayout 的 X/Y。
想让两个框交叠更多：让两组 X 更接近。
```

注意：不要只拖 `CharacterSelectCard_female` 或 `CharacterSelectCard_male`，否则运行时可能会被布局节点覆盖。要改运行时效果，请改 `CharacterSelectCardLayouts` 下面的四个 Layout 节点。

### 8. 选中高亮边框

节点：

```text
CharacterSelectCard_female > CharacterSelectCardHighlight
CharacterSelectCard_male > CharacterSelectCardHighlight
```

可改：高亮边缘的位置和 Content Size。

默认值：

```text
Position: 0, 0
Content Size: 492 x 264
```

注意：运行时只有当前选中的角色框会显示高亮。

### 9. 名字输入框

节点：

```text
CharacterCreatePanel > CharacterNameRoot
```

子节点：

```text
InputNameBg       名字输入框底图
NameDisplayText   显示出来的角色名文字
NameInputCursor   输入光标
InputName         真实输入框点击区域
BtnRandomName     随机名字按钮
```

默认值：

```text
CharacterNameRoot Position: 0, -616
InputNameBg Position: 0, 52.206 / Content Size 462 x 86
NameDisplayText Position: 0, 59.206 / Content Size 320 x 56
InputName Position: 33.6, 59.206 / Content Size 220.479 x 56
BtnRandomName Position: 196, 52.206 / Content Size 70 x 70
```

### 10. 确认按钮

节点：

```text
CharacterCreatePanel > BtnConfirmCreate
```

默认值：

```text
Position: 0, -685.501
Content Size: 344 x 98
```

## 改坏了怎么恢复

如果只是角色选择页改乱，可以让 Codex 执行“恢复角色选择页默认布局”。默认布局就是本文上面写的这些 Position、Scale、Content Size。

不要用 `git reset` 或删除场景节点。
