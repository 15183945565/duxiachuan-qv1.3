# 乱世争雄编辑说明

更新时间：2026-08-05

本页只记录 `Qv1.3` 当前乱世争雄页面在 Cocos Creator 编辑器里的落点。后续改乱世争雄时，先确认打开的是：

```txt
C:\Users\34158\Desktop\game\Qv1.3
```

Prefab：

```txt
assets/Bundle/UIHome/Prefabs/Page/DuelPanel.prefab
```

## 1. 总层级

乱世争雄所有内容都在：

```txt
DuelPanel
  DuelLuanshiZhengxiongPage
```

内部必须按页面分层：

```txt
DuelLuanshiZhengxiongPage
  LuanshiZhengxiongMainPage     // 第一个战斗页面
  LuanshiRecordPage             // 记录页
  LuanshiRankPage               // 排行页
```

不要把 `LuanshiRecordPage`、`LuanshiRankPage` 放进 `LuanshiZhengxiongMainPage`。记录和排行是整页同级节点，打开时会隐藏主战斗页，关闭后再恢复。

## 2. 主战斗页面

主战斗页面节点：

```txt
DuelLuanshiZhengxiongPage/LuanshiZhengxiongMainPage
```

常改区域：

```txt
LuanshiZhengxiongMainPage
  LuanshiZhengxiongBackground
  LuanshiZhengxiongTopHud
  LuanshiZhengxiongTimerBg
  LuanshiZhengxiongRoundStartFxRoot
  LuanshiZhengxiongAvatarLayer
  LuanshiZhengxiongSkillEffectLayer
  LuanshiZhengxiongBottomDock
  LuanshiZhengxiongJoinLayer
  LuanshiOwnedYuanbaoRoot
  LuanshiWudangInvestYuanbaoRoot
  LuanshiGaibangInvestYuanbaoRoot
```

`LuanshiZhengxiongTimerBg` 是结算/助力剩余时间底框。它下面或同区域的期数、VS、血条、阵营图标属于顶部 HUD，不要用运行时代码硬覆盖编辑器坐标。

## 5. 大招全屏特效

大招技能配置在：

```txt
assets/Script/UI/Home/HomeDuelConfig.ts
```

当前两个大招：

```txt
ultimate_1
ultimate_2
```

对应编辑器占位节点：

```txt
LuanshiZhengxiongMainPage/LuanshiUltimateEffect_ultimate_1
LuanshiZhengxiongMainPage/LuanshiUltimateEffect_ultimate_2
```

两个大招都是全屏特效，动画默认播放 `action`。`ultimate_1` 默认朝右，玩家选择右侧丐帮阵营时需要左右翻转。用户说“位置不对、要占满全屏”时，优先让这两个占位节点在编辑器里可选可调，再同步运行时读取编辑器位置和缩放。

## 6. 记录页

节点：

```txt
DuelLuanshiZhengxiongPage/LuanshiRecordPage
```

主滚动区：

```txt
LuanshiRecordPage/LuanshiRecordMainScroll
LuanshiRecordPage/LuanshiRecordMainScroll/LuanshiRecordMainContent
```

内容结构：

```txt
LuanshiRecordMainContent
  LuanshiRecordRecentPanel       // 近 10 期乱世争雄记录
  LuanshiRecordSummaryPanel      // 我参与的记录
  LuanshiRecordPersonalRow_1
  LuanshiRecordPersonalRow_2
  ...
```

文案规则：

- 江湖逃杀的“成功躲避”在乱世争雄里改成“胜利次数”。
- 记录信息右侧只显示“胜利/失败”。
- “袭击”改成“胜方”。
- 记录页不能出现主战斗页的伤害数字、加入阵营按钮、技能底框、排行/记录按钮。
- 只保留左下角返回按钮；不要出现两个返回按钮。

## 7. 排行页

节点：

```txt
DuelLuanshiZhengxiongPage/LuanshiRankPage
```

排行滚动列表：

```txt
LuanshiRankPage/LuanshiRankStreakList
LuanshiRankPage/LuanshiRankStreakList/LuanshiRankStreakContent
```

排行行：

```txt
LuanshiRankStreakRow_1
LuanshiRankStreakRow_2
...
LuanshiRankStreakRow_10
```

`LuanshiRankStreakRow_1` 是优先同步模板。用户改好第一行后，要同步其他排行行的子节点结构、尺寸、坐标、字体、颜色、描边和对齐。乱世争雄排行列名是“连胜次数”，不是江湖逃杀的“投入元宝数”。

用户问“滑动区域在哪里改”时，答案是 `LuanshiRankStreakList` 和 `LuanshiRankStreakContent`；不要指到 `LuanshiZhengxiongJoinLayer`。

## 8. 代码注意

- `HomeFeatureDuelLuanshi.ts` 负责页面壳、主页面层级、底部技能栏、记录/排行入口。
- `HomeFeatureDuelLuanshiBattle.ts` 负责战斗、技能释放、血量、结算、货币显示。
- `HomeFeatureDuelRecord.ts` 里包含乱世争雄记录页刷新逻辑。
- `HomeFeatureDuelRank.ts` 里包含乱世争雄排行页刷新逻辑。
- `HomeDuelConfig.ts` 里是乱世争雄资源路径和默认坐标。

`getOrCreateDuelLuanshiEditableNode`、`getOrCreateDuelLuanshiEditableSkin` 这类 helper 只允许有一份具体实现。其他 Feature 如果要调用，只写 abstract 契约；否则 Cocos 会报 `Cannot compose ... already exists`。

Prefab 批量复制节点后必须跑：

```bash
npm run check:scene
npm run check:ui
```

`check:scene` 会检查重复 prefab `fileId`。如果编辑器层级面板提示过滤重复 UUID 节点，优先查是不是克隆节点时保留了旧 `cc.PrefabInfo.fileId` 或 `cc.CompPrefabInfo.fileId`。
