# 前端完成度与待办

## 已打通的演示流程

- 加载、修复入口、手机号输入、验证码和进入游戏。
- 首次创建角色、男女切换、随机名和名称输入。
- 主界面 HUD、头像资料、左右功能入口和底部导航。
- 角色装备替换、经验升级、突破、强化和成功动画。
- 背包、图鉴、装备分解、兽脉装备排除和合成入口。
- 邮件、托管奖励邮件、领取奖励弹窗、公告、商城、集市和排行。
- 对决和展台的前端演示流程。
- 征战升级、普通挑战、定向挑战、托管、战斗和奖励展示。
- 魔界九重、层数选择、地图移动、怪物挑战和兽卡切换。

## 仍是前端演示数据

- 登录验证码和 token。
- 角色、货币、经验、战力、材料和装备数量。
- 邮件、商城、集市、排行和社交状态。
- 升级、突破、强化、分解和合成结果。
- 战斗伤害、胜负、掉落、挑战次数和托管产出。

这些值只用于当前离线流程演示。后端接入后必须由服务端快照覆盖，客户端不得同时保留第二份线上真值。

`IGameBackend`、`LocalPreviewBackend` 和 `RemoteGameBackend` 已存在，但目前只有 `MainHomeView` 发起一次未回填 UI 的 `initialize()`；其余页面事务仍主要操作本地状态。因此“有接口类”不等于“已经可以直接联调”。

宗门、礼包仍按当前产品决定冻结。分享任务与道友页面已解冻并完成前端演示迁移，当前仍使用本地演示数据，不纳入首版线上联调验收。

## 后端接入后的前端工作

- 给所有接口补 Loading、Empty、Error、Retry 和超时状态。
- 接入 token 刷新、断线重连、维护公告和版本更新。
- 用服务端物品 ID、装备实例 ID 和事务结果替换本地演示数据。
- 对邮件领取、商城购买、市场交易和战斗结算实现幂等反馈。
- 完成真机安全区、低端机资源占用和网络抖动测试。
- 锁定验证码、登录、token 刷新、错误码、幂等键和版本协商协议。
- 将 Bootstrap 快照真正回填到角色、货币、背包和功能开关，并移除同一字段的本地真值。

## 固定版本约束

- Cocos Creator：`3.8.8`。
- Spine 资源按当前 `3.8.x` 导出包继续维护。
- 正式角色路径保持 `Spine/Role/男角色` 和 `Spine/Role/女角色`。
- MainScene 挂载类名保持 `MainHomeView`。
