# 项目交接总览

## 交付身份

`Qv1.3` 是当前唯一继续开发和交付的独立 Cocos Creator `3.8.8` 前端工程。它包含场景、源码、正式 UI/Spine/音频资源、项目设置、检查工具、Release 构建配置和交接文档，不把编辑器缓存、构建输出、日志、截图、临时切图或历史备份当作源码交付内容。

当前前端流程可离线演示；账号、货币、背包、装备、邮件、排行、交易、升级和战斗结算的线上真值必须由后端接管。

## 场景流程

```text
LoadingScene
  -> 资源与配置加载
  -> 手机号登录
  -> MainScene
  -> 新账号创建角色
  -> 主界面与各功能页
```

## 技术边界

- MainScene 只保留场景壳、常驻 HUD、导航与分层根节点；Home 页面和弹窗以编辑器 Prefab 管理。
- 邮件、排行、背包格子、战斗伤害数字等重复数据节点由模板或运行时代码生成。
- UI 路径、尺寸、演示配置集中在 `HomeConfig.ts`。
- 页面 DTO、状态类型和 Inspector 布局类型集中在 `HomeTypes.ts`。
- 本地演示实现为 `LocalPreviewBackend`；现有 UI 仍有部分独立 localStorage 状态。
- 正式 HTTP 参考实现为 `RemoteGameBackend`，但登录、快照回填和各页面事务尚未完成端到端绑定。
- 后端切换入口为 `GameBackend.configure(...)`。
- 九个按需功能资源包为 `feature-magic/battle/duel/beast/shop/profile/bag/role/share`。

## 主界面代码职责

| 文件 | 职责 |
|---|---|
| `MainHomeView.ts` | 生命周期、启动编排、Prefab 挂载和功能 Scope 所有权 |
| `HomeViewBase.ts` | 组合层公共状态和显式 Feature 契约 |
| `HomeViewRoleBag.ts` | Role/Bag/Duel 等遗留状态初始化与少量共享适配 |
| `HomeViewAdventure.ts` | Battle/Magic/Beast 遗留状态初始化与共享确认适配 |
| `HomeFeature*.ts` | 按玩法职责拆分的无状态功能模块 |
| `HomeAssetBundleManifest.ts` | 点击入口到功能 Bundle 的唯一资源路由 |
| `HomeUIPrefabManifest.ts` | 启动/按需 Prefab 分组 |
| `HomeConfig.ts` | 资源路径、布局常量、数值表和前端演示数据 |
| `HomeTypes.ts` | UI、业务 DTO 和 Inspector 配置类型 |

场景仍挂载 `MainHomeView`，脚本 UUID 保持不变。

npm run check:all
